# Archived CIFAR source addendum 20261002

This addendum supports Reviewer 4 Comments 10 and 15. It preserves 59 of the
60 approved CIFAR-10 LF seed configurations as archived CSV summaries. Three
metrics (Best, Avg, ASR), algorithm, ratio and filename seed must agree with the
author-designated workbook. Duplicate backup files are not independent repeats.

Run `python verify.py` from this directory using Python 3.9+ standard library.
The verifier checks immutable file hashes and each recorded CSV row against the
cell-addressed workbook extract. No GPU, spreadsheet software or network is
required. Table 2/3 values are unchanged. The workbook is represented by a source
extract and whole-file hash; the original spreadsheet is not included.

The original 32-configuration server record also includes 41 sampled rounds per
configuration. This addendum does not recover complete 200-round histories.
Execution-time seed logs, historical code/environment certification and remaining
MNIST/Fashion-MNIST and CIFAR SF/Scaling main-table histories remain incomplete.
It extends the selected evidence snapshot; it is not a full-history reproduction.
